# 1986피트니스 중산점 웹사이트 디자인

## 목표

중산동에서 헬스장을 찾는 방문자가 실제 회원들이 오래 다니는 이유를 이해하고 네이버 예약, 전화 또는 카카오 상담으로 이동하게 한다. 회원권 가격이나 무료 OT를 첫 설득 근거로 사용하지 않는다.

## 확인된 사실

- 네이버 플레이스: 별점 4.97, 리뷰 2,864건, 24시간 운영으로 표시되어 있다(2026-09-05 확인).
- 리뷰 키워드: 친절해요 1,111, 시설이 깔끔해요 956, 기구가 다양해요 756, 공간이 넓어요 561, 자세를 꼼꼼히 봐주세요 551.
- 위치: 경기 고양시 일산동구 중산로 244 고은프라자 6층.
- 공간: 지상 300평, 개인 샤워부스, 유산소·웨이트 머신, 스트레칭 존.
- 중산동에서 가장 오래 운영된 헬스장이며 KEEPAY 먹튀방지 안심매장에 가입되어 있다(사업주 제공 정보).
- 트레이너: 박세준(바디프로필·힙·임산부 레슨), 정윤수(다이어트·재활·근력 웨이트), 이재승(바디프로필·프리웨이트).
- 실제 리뷰에는 재등록, 12개월 등록, 다시 방문, 직원과 친해져 편하게 이용한다는 경험이 존재한다.

장기회원의 정확한 인원이나 비율은 공개 자료로 확인되지 않으므로 수치로 만들지 않는다. 대신 실제 리뷰 문장과 행동을 근거로 표현한다.

## 디자인 접근

### 선택안: 사람과 공간이 만드는 장기 이용 경험

메인 카피는 “오래 다니는 데는, 분위기가 이유가 됩니다.”로 한다. 친절한 직원, 정돈된 공간, 시간 제약 없는 이용을 하나의 경험으로 묶는다. 24시간·300평·중산동 최장 운영·KEEPAY 가입은 주인공을 뒷받침하는 신뢰 근거로 배치한다.

비교안 1인 시설 중심 구성은 경쟁 헬스장과 구분이 약하고, 비교안 2인 가격 중심 구성은 장기회원과 분위기라는 실제 강점을 가린다. 따라서 사람과 분위기를 앞세우고 시설을 증명 자료로 사용하는 선택안을 채택한다.

## 정보 구조

1. 첫 화면: 분위기 약속, 실제 공간 사진, 방문 상담 CTA
2. 오래 다니는 이유: 친절함·청결·공간·기구의 리뷰 근거
3. 공간 아카이브: 지상층, 웨이트, 유산소, 샤워·라커
4. 회원 경험: 재등록과 편안함을 보여주는 실제 리뷰 요약
5. 트레이너: 확인된 3명과 공개된 전문 분야
6. 방문 안내: 주소, 24시간, 휴무 안내, 전화·네이버·카카오 링크

## 시각 방향

- 원흥점의 에디토리얼한 큰 제목과 여백, 가양점의 명확한 숫자·동선 표현을 참고한다.
- 중산점은 따뜻한 아이보리, 차콜, 짙은 올리브와 따뜻한 주황 포인트를 사용한다.
- 균등 카드 그리드를 피하고, 실제 사진이 크게 흐르는 비대칭 편집 레이아웃을 사용한다.
- 제목은 단단한 한국어 산세리프, 본문은 읽기 쉬운 시스템 산세리프를 사용한다.

## 시그니처 구성과 컴포넌트

시그니처 구성은 첫 화면의 `LONG STAY / 24 HOURS` 세로 레일과 실제 운동 공간 사진을 겹치는 비대칭 프레임이다. 시그니처 컴포넌트는 회원이 오래 다니는 이유를 리뷰 키워드와 짧은 경험 문장으로 연결하는 `STAY REASONS` 트랙이다.

## 상호작용과 모션

- 첫 진입: 지점명, 메인 문장, 사진 프레임, CTA가 순차적으로 조립된다.
- 스크롤: 섹션 번호와 제목이 먼저 나타나고 사진·근거가 짧은 간격으로 이어진다.
- 시설 갤러리: 선택한 사진이 확대되고 라벨과 설명이 교체된다.
- 트레이너: 카드 선택 시 해당 인물의 전문 분야가 강조된다.
- CTA와 내비게이션에는 위치 이동과 포커스를 명확히 보여주는 피드백을 준다.
- `prefers-reduced-motion`에서는 이동 애니메이션을 제거하고 최종 상태를 바로 표시한다.

## 반응형

- 데스크톱: 비대칭 12열 그리드, 큰 시설 이미지와 고정형 정보 레일.
- 모바일: 첫 화면 사진 초점을 유지하며 텍스트를 사진 아래로 이동한다. 시설 갤러리는 가로 스냅 트랙, 트레이너는 탭형 선택으로 전환한다.
- 320·360·390·430px에서 가로 넘침, 한국어 제목의 어색한 음절 분리, CTA 잘림을 확인한다.

## 콘텐츠 원칙

- 공개된 실제 중산점 사진과 등록된 트레이너 자료만 사용한다.
- 원흥점·가양점의 문구, 사진, 전체 레이아웃은 복사하지 않는다.
- 장기회원 수, 성과 수치, 자격증, 고객 발언을 임의로 만들지 않는다.
- 가격과 이벤트는 변경 가능성이 높으므로 고정 본문에 넣지 않고 네이버 플레이스로 연결한다.

## 기술 구조

- GitHub Pages에 바로 배포되는 정적 HTML, CSS, JavaScript 구조로 제작한다.
- 외부 빌드 서비스, API 키, 서버, 데이터베이스는 사용하지 않는다.
- 시맨틱 HTML, 키보드 포커스, 이미지 대체텍스트, 모션 감소 설정을 포함한다.
- 연락 CTA는 전화, 네이버 플레이스/예약, 카카오 채널의 실제 URL로 연결한다.
