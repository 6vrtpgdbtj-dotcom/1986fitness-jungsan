# 네이버 플레이스 콘텐츠 동기화 설계

## 목적

네이버 플레이스에 등록한 중산점 소식과 업체 사진을 사이트의 `LIVE FROM NAVER` 영역에 자동 반영한다.

## 제약

- 네이버는 스마트플레이스 사진·소식 조회용 공식 공개 API를 제공하지 않는다.
- GitHub Pages는 서버 코드를 실행할 수 없으므로 GitHub Actions가 정기적으로 공개 페이지를 읽고 정적 JSON을 생성한다.
- 동기화는 매시간 실행되며 GitHub Actions 지연을 포함하므로 엄밀한 실시간이 아니다.
- 네이버 구조 변경이나 차단으로 실패할 수 있다.

## 구조

1. `scripts/sync-naver.mjs`가 중산점 네이버 공식 블로그 RSS를 읽는다.
2. 공개된 글 제목·본문 요약·날짜·링크와 대표 이미지 URL을 추출한다.
3. 소식이 최소 1개일 때만 `data/place-feed.json`을 교체한다.
4. `.github/workflows/sync-naver-place.yml`이 매시간 실행하고 변경분을 저장소에 커밋한다.
5. 사이트는 JSON을 읽어 최대 4개 항목을 표시한다. 로딩 실패 시 기존 HTML 폴백과 네이버 링크를 유지한다.

## 안전성

- 로그인, 예약, 문의 등 외부 상태를 변경하는 동작은 수행하지 않는다.
- 저장소에 인증정보를 넣지 않는다.
- 네이버 플레이스의 접근 제한을 우회하지 않으며 공개 RSS 이미지만 대상으로 한다.
- 빈 결과, 차단 화면, 파싱 실패 시 마지막 정상 JSON을 보존하고 작업을 실패 처리한다.

## 검증

- 고정 HTML fixture로 파서의 소식·사진 추출 및 빈 결과 거부를 검사한다.
- 사이트 소스에서 로딩·성공·오류 상태를 검사한다.
- 실제 네이버 페이지를 대상으로 수동 실행해 JSON 스키마와 이미지 URL을 확인한다.
